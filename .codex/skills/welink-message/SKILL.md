# WeLink 发消息

通过 macOS 桌面版 WeLink 给指定联系人发送一条用户提供的消息。WeLink 的
Accessibility tree 可能只暴露窗口外壳，不稳定暴露聊天控件，因此必须使用
Computer Use 操作并通过截图做视觉核对。

## 输入

- `recipient`：联系人姓名、拼音、备注名或部门群名。
- `message`：要发送的完整文本。

缺少任一字段时停止。不要自行补写或改写消息正文。

## 发送授权

当上游任务明确提供 `recipient` 和完整 `message`，并已通过应用的管理员授权与
任务确认流程时，视为已授权发送，不在最终点击发送前再次询问。

以下情况必须停止：搜索结果出现多个无法区分的目标；无法视觉核对当前会话就是
`recipient`；正文无法完整、原样进入输入框；WeLink 未登录、弹出权限请求或窗口
不可用；上游任务标记为预检或 dry-run。

## 操作流程

1. 打开或切换到 WeLink。
   - 使用 Computer Use 读取 `com.huawei.cloud.welink`。
   - 如果 WeLink 未登录、弹出权限请求或窗口不可用，停止。

2. 定位联系人。
   - 优先从当前会话列表中选择视觉上与 `recipient` 完全匹配的联系人。
   - 必须搜索时，使用 WeLink 顶部搜索框并选择“联系人”分类。
   - 搜索结果出现多个同名目标时停止，不要猜测。

3. 打开会话并核对目标。
   - 查看会话标题、头像旁姓名或群名，确认当前会话是 `recipient`。
   - WeLink 可在姓名后附加空格和纯数字员工号；姓名部分仍必须逐字匹配。

4. 输入消息。
   - 中文、全角标点或其他非 ASCII 文本必须优先通过 macOS 剪贴板粘贴。
   - 上游 Action 会提供一个权限为 `0600` 的临时正文文件。用固定命令
     `/usr/bin/pbcopy < '<message_file>'` 把原文放入剪贴板，再用 Computer Use
     点击输入框并按 `Cmd+V`。
   - 不要用 Computer Use `type_text` 直接输入中文；WeLink 可能丢字或不输入。
   - 如果草稿乱码、缺字或残留旧内容，不得发送；在输入框内 `Cmd+A` 后重新粘贴
     原文，并再次视觉核对。

5. 发送前核对。
   - 视觉核对会话目标与完整草稿。
   - 收件人或正文不一致时，修正后重新核对；无法修正时停止。

6. 发送并验证。
   - 只点击一次发送按钮，不自动重试。
   - 点击后立即重新调用 `sky.get_app_state`。
   - 只有明确看到消息出现在当前会话末尾，才可报告已发送。
   - 反馈不明确时报告终态不确定，禁止再次点击发送。

## 记录与汇报

- 只报告目标、状态和受控原因码。
- 不输出与本次任务无关的聊天内容、联系人列表、剪贴板内容或凭据。
- 上游要求截图证据时，最终截图必须同时包含当前会话标题与刚发送的消息。
