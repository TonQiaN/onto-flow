# 节点自带完整定义，Action 库降为模板

推翻 [ADR-0004](0004-canvas-edits-the-shared-action.md)。画布上的一个 agent 节点就是一个
Action，它自带自己的完整定义——任务、规则、端口、出口端口、产物、模型、思考强度——并归它
所在的那个工作流所有。库里存的是 **Action 模板**：把模板放上画布得到一个 Action，此后两者
再无关系，改模板不影响已放下的 Action，改 Action 也不回写模板。

理由：这套编排的用法是人手工编排与反复调试单个角色的提示，共享实体让"调一个工作流里的评委"
波及所有引用它的工作流，调试回路因此被拉长；一个工作流自包含也让整图重跑与历史解释只需要看
一处。代价很实在：Action 模板不再被引用，`usedByNames()` 那道删除保护对它失效，跨工作流的复用
退化为复制——同一段提示改好了要手工同步到每个用到它的工作流，ADR-0004 当初防的正是这种分散。
