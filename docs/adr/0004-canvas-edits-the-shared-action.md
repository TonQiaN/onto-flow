# 画布上编辑 Action 编辑的是共享实体，不引入实例级覆盖

可以在工作流画布上双击节点直接编辑它引用的 Action，但编辑对象始终是**那个共享的
Action 本身**，改动对所有引用它的 Workflow 同时生效。节点仍然是纯引用，不带任何
实例级覆盖字段。为了让影响面可见：编辑面板常驻"被 N 个工作流引用"的提示并可展开
跳转；破坏性改动（改端口名、删端口）保存前列出会失效的连线；面板提供
「复制为新 Action 并替换本节点」，供只想改一处时使用。

理由：实例级覆盖会让"这个节点实际跑的是什么配置"分散在两处（库里的基线 + 节点上的
覆盖），排查成本翻倍，而排查成本正是这类系统的主要成本。代价是编辑共享实体天然有
波及风险，因此把影响提示、失效连线预览、一键 fork 三件事做成硬性配套，而不是可选项。
历史可解释性由[[运行快照]]保证：每次运行冻结当时的完整配置，事后改动不影响历史记录。
