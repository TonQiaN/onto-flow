## 必须覆盖的矩阵

| 问题 | 场景 | 证明层 | 通过标准 |
| --- | --- | --- | --- |
| F03 | 从空图新增六节点，拖出七条边 | Playwright + 视觉 | 同口汇总、返工回边均落盘，保存重载不丢边 |
| F03 | 扇出、同口汇总、合法回边、反向拖线 | 共享规则单测 + Playwright | 与服务端同判定，UI 高亮和实际提交一致 |
| F03 | 重复边、类型不符、目标没有重入上限 | 单测 + Playwright | 不添加边，出现可见原因；不误伤无关未连输入 |
| F03 | 添加连线按钮与回边说明 | Playwright + 视觉 | 可选节点和端口；显示目标、重入次数、耗尽行为 |
| F04 | 缺必填项、额外字段、类型错误、无效 JSON | 单测 + 引擎集成 | 节点失败，失败证据保留，下游不能成功 |
| F04 | 合法 JSON、纯文本与文件 | 单测 + 引擎集成 | 正常通过，文本不被当成 JSON |
| F04 | Schema 写边界、冻结版本、校验入口 | API/单测 + Playwright + 视觉 | 拒绝无效契约；运行使用受理版本；反馈指向字段 |
| F05 | 抽屉一直打开，running → 终态 | Playwright + 真实运行 + 视觉 | 不切页、不重开即看到输出或失败原因 |
| F05 | 切节点、切轮次、迟到请求 | Playwright | 不串用旧内容，已结束轮次稳定缓存 |
| F05 | 读取失败、手动刷新、未产出、被清理 | Playwright + 视觉 | 四种状态不同，刷新可恢复，轨迹页不预取载荷 |

## 工程门槛

- 每层：先证明原行为回归失败，再执行对应单测和浏览器测试；`npm run check` 与 `npm run build` 通过后提交。
- CI：现有 `check` 与 `e2e` 作业自动覆盖新增测试；CI 不携带模型凭据。付费真实验收单独记录。
- 测试夹具：按 spec 使用 `e2e-` 前缀并精确清理；不依赖体验数据或原有工作流。浏览器门禁不发起含 Action 的付费运行。
- 最后一层交付前：核对三个 PR 的 base/head、完整 CI 状态、当前界面截图和实际运行；记录对应命令、结果和限制。
